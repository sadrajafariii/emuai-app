# bud Browser Extension

Highlight any text on any webpage → click "⚡ Ask bud" or right-click → "Ask bud".

## Install (Chrome / Brave / Edge)

1. Open your browser and go to `chrome://extensions`
2. Enable **Developer mode** (top right)
3. Click **Load unpacked**
4. Select this folder: `browser_extension/`
5. The bud icon appears in your toolbar

## Usage

- **Highlight text** on any page → a gold "⚡ Ask bud" bubble appears → click it
- **Right-click** selected text → "Ask bud: [text]"
- **Click the toolbar icon** → opens bud

## Note

Make sure bud is running at `http://127.0.0.1:8082` before using the extension.
