# Chrome Web Store Listing

## Name
bud AI — Browser Extension

## Short description (132 chars max)
Let bud AI browse the web in your Chrome. Opens a dedicated tab group, streams screenshots live to the bud interface.

## Detailed description
bud is a personal AI agent that can browse the web, run code, manage files, and remember things across conversations.

This extension connects bud to your real Chrome browser so it can:

• Open websites in a dedicated "bud" tab group — completely separate from your personal tabs
• Stream live screenshots back to the bud interface so you can watch it work
• Click, scroll, type, and interact with pages on your behalf
• Close its tab group cleanly when done

Without the extension, bud uses a headless browser you can't see. With it, you watch everything happen live in your own Chrome.

**How it works:**
1. Install the extension
2. Open bud at emuai.org or localhost:8082
3. The sidebar shows "Chrome connected" in green
4. Ask bud to browse anything — it opens in a yellow "bud" tab group in your Chrome

**Privacy:**
The extension only connects to your local bud server (127.0.0.1:8082) or emuai.org. It never sends data anywhere else.
